- Corretor's Oferta Ativa is one module (`src/components/oferta-ativa-v2`, page `OfertaAtivaCorretor` on /corretor/call and /arena-ligacoes): one call screen for Listas/Estagnados/Descartados via the `useFilaOA` adapter, writing only through existing server functions. Why: one UI and one data path so panels, ranking, TV and reports never diverge.
- Late conversions from the call history go only through `oa_historico_aproveitar` (checks own call, opt-out and current Pipeline owner; logs canal='retorno' so it counts as aproveitado, never as a call). Old Mutirão/Arena/discador screens were removed; their routes open this module. Why: one door for every aproveitado and no duplicate owners.
